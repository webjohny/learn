# Phrase Deck

Флеш-картки для розмовних фраз: інтервальні повторення (SM-2), мікро-сесії на хвилину, активне пригадування через набір тексту, TTS та cloze-блюр. Працює офлайн; з акаунтом синхронізує колоди між пристроями.

## Запуск

```bash
npm install
npm run dev      # web :5173 + API :8787 (concurrently)
npm run build    # vite build → dist/ ; nest build → dist-server/
npm start        # прод: один процес роздає API і зібраний фронтенд
npm run test:api # наскрізний smoke-тест API (сервер має бути піднятий)
```

Дані сервера — SQLite-файл `data/phrase-deck.sqlite` (шлях змінюється через `DB_PATH`), порт — через `PORT`.

## Стек

**Фронтенд:** Vite 6 · React 18 · TypeScript (strict) · Tailwind CSS v4 · Framer Motion · Zustand + persist.
**Бекенд:** NestJS 11 · вбудований `node:sqlite` (без нативних залежностей) · class-validator · сесії в httpOnly-cookie, паролі — scrypt.

PWA-friendly: маніфест, `theme-color`, safe-area, standalone-режим.

## Акаунти та мовні пари

Без акаунта все працює локально в колоді `local`. Після входу картки гостя переносяться в акаунт, якщо серверна колода порожня.

Колода = **мовна пара** (`sourceLang → targetLang`). Пара визначає голос TTS: у парі `uk → de-DE` відповідь читає німецький голос. Пар може бути скільки завгодно, у кожної власний прогрес і серія днів.

### Синхронізація

Двофазна: спершу `pull` серверних змін, потім `push` локальних.

- **Картки** — last-write-wins за `updatedAt`; видалення м'які (`deletedAt`), щоб доїхати до інших пристроїв.
- **Денна статистика** — злиття за максимумом лічильників: вони лише зростають, тож два пристрої за один день не затирають одне одного.
- Позначка `lastSyncAt` рухається **лише після успішного push** — інакше локальні правки загубилися б при збої мережі.
- Офлайн не є помилкою: зміни лягають у `localStorage` і поїдуть при відновленні зв'язку.

## API

| Метод | Маршрут | Призначення |
| --- | --- | --- |
| `POST` | `/api/auth/register` · `/login` · `/logout` | сесія в httpOnly-cookie |
| `GET` | `/api/auth/me` | поточний користувач + його колоди |
| `GET/POST/PATCH/DELETE` | `/api/decks` | мовні пари |
| `GET` | `/api/sync/:deckId?since=` | зміни після мітки часу |
| `POST` | `/api/sync/:deckId` | надіслати локальні зміни |

## Режими навчання

| Режим | Що робить |
| --- | --- |
| **Інтервали** | SM-2 з чотирма оцінками. `Забув` повертає картку в поточну сесію через 10 хв. Нові картки перемішуються між повтореннями. |
| **Спринт** | Тайм-атак на 60 с (налаштовується): 10 випадкових карток, дві кнопки «Знав / Не знав». |
| **Друк** | Активне пригадування: користувач набирає фразу, додаток рахує схожість Левенштейна, підсвічує помилкові слова та пропонує оцінку. |

## Керування

**Клавіатура:** `Space` — перевернути · `1–4` або `←↓→↑` — оцінка · `S` — озвучити · `E` — редагувати картку · `Esc` — закрити вікно.

**Дотик:** тап — перевернути; після перевороту свайп ← «Забув», → «Добре», ↑ «Легко», ↓ «Важко» (з вібровідгуком).

## Формат JSON

Імпорт приймає масив карток або повний бекап (`{ version, cards, settings, days, log }`). Обов'язкові лише `front` і `back` — решта підставляється:

```json
[
  {
    "id": 1,
    "category": "Morning & Coffee",
    "front": "Нічого особливого, просто розгойдуюся зранку.",
    "back": "Not much, just *[getting through]* the morning.",
    "tags": ["casual", "morning"],
    "difficulty": "medium",
    "note": "fuel up — «заправитися»",
    "nextReview": null,
    "interval": 1,
    "repetition": 0,
    "efactor": 2.5
  }
]
```

Фрагменти в `*[дужках]*` — cloze: на звороті вони показуються під блюром і відкриваються кліком.

Експорт двох видів: **колода** (чисті картки) і **бекап** (картки + прогрес + налаштування + журнал повторень).

## Нотатки

- Денні ліміти (`newPerDay`, `reviewsPerDay`) обмежують чергу; лічильник у шапці показує, скільки реально буде показано.
- Серія днів рахується за локальним часом, не UTC.
- Час практики капається 60 с на картку — вкладка, залишена відкритою, не накручує статистику.
- TTS використовує Web Speech API; голос і швидкість обираються в налаштуваннях.
