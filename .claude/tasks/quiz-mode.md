### 4.3 Модель даних (пропозиція)

```ts
export type QuizMode = 'graded' | 'survey'
export type QuizQuestionType = 'single' | 'multiple' | 'open'

export interface QuizAnswerOption {
  id: string
  text: string
  correct: boolean
}

export interface QuizQuestion {
  id: string
  text: string
  type: QuizQuestionType
  imageUrl?: string
  /** Порожній для 'open' */
  answers: QuizAnswerOption[]
}

export interface Quiz {
  id: string
  title: string
  description?: string
  mode: QuizMode
  questions: QuizQuestion[]
  createdAt: string
  updatedAt: string
}
```

Формат JSON-імпорту = цей самий об'єкт (або масив таких), з опційними
`id`/`createdAt` — як `CardImport` відносно `Card` (`src/types.ts:33`).
